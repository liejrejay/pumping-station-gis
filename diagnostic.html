解決方案建議

常見問題與解決方法：

  1. API Key 網域限制
    • 前往 Google Cloud Console
    • 編輯你的 API Key
    • 在 "HTTP referrers" 中新增：*.github.io/*
    • 儲存設定（可能需要 5-10 分鐘生效）
  2. 計費未啟用
    • 前往 Google Cloud Billing
    • 確保專案已連結到計費帳戶
    • 啟用 Maps JavaScript API
  3. API 未啟用
    • 前往 Maps JavaScript API
    • 點擊 "啟用" 按鈕
